# General AI Fluency - Impact Project: Portfolio Maintenance & Next Case Plan

## 1. How to Add the Next Case Study (The Three-Beat Shape)
To ensure the portfolio continues growing without going stale, every future project will be added using the standard Week 2 three-beat framework:
- **The Problem:** Define the concrete user pain point, system inefficiency, or technical challenge.
- **What You Did:** Describe the architecture, tool stack (Python, Node.js, DuckDB, ML pipelines), and execution steps.
- **What Came of It:** Detail the measurable outputs, performance gains, or deployed deliverables.
- **Publishing Steps:** Draft the markdown/HTML, integrate it into the repository structure, commit updates, and verify GitHub Pages deployment.
