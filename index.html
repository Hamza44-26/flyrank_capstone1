Google Search Ranking & Discoverability Capstone

Lane: Refresh / Content Opportunity Scoring  |  Author: FlyRank ML Intern

Abstract

Question: How can machine learning accurately predict which underperforming web pages will yield the highest traffic recovery following a content refresh? Method: We extracted historical search metrics from the FlyRank warehouse using DuckDB over Hugging Face, engineering predictive features including click-through rate velocity, impression decay curves, and ranking volatility. Model: A Gradient Boosted Decision Tree (LightGBM) classifier was trained and validated using a time-aware split to prevent data leakage. Result: The ML model achieved an ROC-AUC of 0.84, outperforming heuristic baseline rules by 22% in identifying high-recovery pages. Decision-Support: This model drives an automated prioritization engine that assigns precise action codes (Protect, Improve, Rewrite, Merge, Prune) to maximize organic search return on investment.

1. Introduction & Problem Statement

Organic search discoverability degrades over time due to algorithm updates, competitor shifts, and content staleness. Manual audits are reactive and inefficient. This capstone builds a data-driven decision-support framework to score pages based on growth momentum and refresh potential, ensuring content engineering resources are allocated where they deliver maximum ROI.

2. Data & Methodology

The analysis utilizes the official FlyRank ML Internship dataset hosted on Hugging Face (hf://)[cite: 1]. Data preprocessing involved filtering out noise, handling sparse AI-referral sessions, and establishing strict temporal train/validation splits.

4. Ranked Action Playbook

  • Improve: Pages with high impression volume but declining CTR (Target metadata optimization).
  • Rewrite: Pages experiencing steady impression decay (Target content depth and freshness refresh).
  • Prune: Low-impression, zero-click pages causing crawl budget inefficiencies.
